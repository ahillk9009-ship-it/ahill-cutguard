# OSS 메인테이너 지원 준비

## 현재 준비된 것

- 독립 실행 가능한 Python 패키지·CLI·선택형 GUI
- 공개 라이선스, 영문 README, 한국어 실행 안내
- 합성 오류 영상과 재현 스크립트
- 자동 테스트와 GitHub Actions 설정
- 기여 가이드·이슈 양식·릴리스 기록·로드맵

## 아직 확보하지 않은 것

- 외부 사용자, 다운로드·스타·실제 도입 근거
- 외부 기여·이슈 대응·지속적인 유지관리 이력
- 실사용 정확도와 시간 절감 측정
- 실제 보고서 화면과 검토 JSON 저장·불러오기의 수동 검증 (실행·파일 선택·검사 완료는 확인: [검증 근거](RELEASE_VERIFICATION_KO.md))

이 자료만으로 지원 선정 가능성을 보장할 수 없습니다. 공식 양식은 사용 현황, 생태계 중요성, 메인테이너 역할을 묻습니다.
https://openai.com/ko-KR/form/codex-for-oss/

## 공개 후 진행 순서

메인테이너가 v0.2.2 공개 알파 릴리스를 승인했습니다. 공개 자체를 사용자 채택이나 유지관리 실적으로 간주하지 않습니다. 아래 후속 사용자 모집·데모 제작은 향후 제안이며 완료한 일이 아닙니다.

1. 공개 알파 릴리스 설명을 유지하고, 별도의 사용법 데모를 준비합니다.
2. 편집자에게 합성 예제와 본인 영상으로 테스트를 요청합니다. 고객 영상의 공개를 요구하지 않습니다.
3. 이슈에 재현 조건·기대 결과·수정 내용을 남깁니다.
4. 결함 유형별 오탐/누락과 수작업 검토 시간을 측정합니다.
5. 실제 수치를 바탕으로 지원서 내용을 작성합니다. 준비 단계의 목표를 달성 실적으로 쓰지 않습니다.

## 향후 API 크레딧 사용 계획 소재

재현 가능한 테스트 작성, 실패 사례의 이슈 분류, 코드 리뷰와 릴리스 자동화에 활용하는 유지관리 계획을 구체화하세요. 제품에 AI API를 추가하는 것과 OSS 유지관리에 Codex를 쓰는 것을 구별해 설명하세요. 현재 제품은 API를 사용하지 않습니다.
