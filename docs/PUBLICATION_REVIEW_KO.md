# CutGuard v0.2.1 공개 가치 검토

> v0.2.1 당시 검토 기록입니다. v0.2.2 소스 커밋 `4c05c3f`는 원격 tests와 release-check를 통과했습니다. 현재 저장소는 비공개이며 원본 데모 업로드와 실제 PC 수동 점검이 남았습니다. 아래의 미실행·미생성 설명과 공개 제안은 과거 상태이며, 현재 결과와 승인 범위는 [RELEASE_VERIFICATION_KO.md](RELEASE_VERIFICATION_KO.md)를 따릅니다. 공개 전환·공개 릴리스는 승인되지 않았습니다.

검토일: 2026-09-17

## 판정

**실험용 공개 알파 툴킷으로 업로드할 가치가 있습니다.** 현업 영상편집자의 반복 검수를 재현 가능한 코드·근거 보고서·검토 기록으로 만들었다는 실용적 가치가 있습니다. 현재는 완성형 상용 대체재, 높은 정확도가 검증된 도구, 또는 OSS 지원 선정 가능성이 높다는 주장을 할 근거가 없습니다.

## 이번에 보완한 기능

- 정상 연출 승인 / 수정 필요 / 미검토 판정과 메모 저장
- 보고서별 SHA-256 식별자로 다른 보고서에 검토 내용이 잘못 적용되는 것을 차단
- HTML에서 검토 JSON 내보내기/불러오기, CLI에서 동일한 검토 파일 생성·갱신
- 두 검사 결과의 유지 / 신규 / 미검출 비교
- 검사 조건이나 영상·자막 검사 범위가 다르면 비교 거부
- 검토 파일·비교 결과의 기존 파일 덮어쓰기 방지
- 정상·오류·의도된 연출 더미 영상 및 재현 자료

## 검증 근거

- Python 3.12 / Linux / FFmpeg 6.1.1에서 32개 unittest 통과
- 검토 UI의 내보내기·불러오기·잘못된 보고서 거부 로직을 Node 모의 DOM으로 검증
- 오류 더미: 7개 항목, 정상 기준본: 0개 항목
- 두 결과 비교: 유지 0 / 미검출 7 / 신규 0
- Python wheel 빌드 및 설치된 명령어 검증
- 기존의 검토 판정은 탐지 항목을 삭제하지 않으며 다른 버전에 자동 이전하지 않음

모의 DOM은 실제 브라우저 검증이 아닙니다. 실제 다운로드·파일 선택·화면 배치와 Windows GUI는 미검증입니다. 모든 검증은 합성 자료 기반이며 실사용 정확도나 절감 시간은 아직 측정하지 않았습니다.

## 기존 도구와 겹치는 부분

FFmpeg의 blackdetect/freezedetect/scene 기능을 사용하므로 탐지 알고리즘 자체가 독창적인 것은 아닙니다. QCTools도 영상 이상 분석·필터·보고서 기능을 제공하는 기존 OSS입니다. 따라서 '세계 최초 영상 QC', '경쟁 도구 없음', 'AI가 모든 오류 자동 수정' 같은 표현은 피해야 합니다.

공식 참고:
- https://ffmpeg.org/ffmpeg-filters.html#blackdetect
- https://ffmpeg.org/ffmpeg-filters.html#freezedetect
- https://github.com/bavc/qctools

CutGuard의 현재 차별화 방향은 한국어 SRT 검사, 숏폼 편집자가 이해하기 쉬운 근거 이미지, 가벼운 로컬 실행, 보고서와 연결된 검토 기록입니다. 이 조합이 실제 사용자에게 선택받는지는 외부 테스트로 확인해야 합니다. 경쟁 제품 전수조사나 기능 우위 검증은 하지 않았습니다.

## 추천 공개 방식

독립 저장소 `ahill-cutguard`에 alpha/prerelease로 공개하고, 기존 creative-toolkit에서는 설치/활용 예제로 연결하는 편을 권합니다. 저장소 이름 사용 가능 여부는 확인하지 않았습니다. 공개 소개는 '한국어 숏폼 편집을 위한 로컬 영상·자막 검수 툴킷'이 적합합니다. 브라우저·Windows의 미검증 범위를 README에서 숨기지 마세요.

현재 사용 요청은 가치 검토까지이므로 GitHub 공개·계정 연결·릴리스 게시를 수행하지 않았습니다. 준비된 ZIP은 비공개 검토 및 이후 공개용 소스로 쓸 수 있습니다.
