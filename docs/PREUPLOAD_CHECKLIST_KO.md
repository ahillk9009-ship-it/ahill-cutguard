- 핵심 검사와 검토 저장·비교 구현

- 더미 정상/오류/의도된 연출 자료, 정답과 결과 포함
- 소스 라이선스·사용법·기여/이슈 양식·릴리스 노트

- 배포 ZIP에서 캐시·빌드 찌꺼기·구버전 wheel 제외

## 공개 후 자동 실행이 필요한 항목

- GitHub Actions 실행 결과 확인: 아직 원격에서 실행한 적이 없습니다.
- 실패할 경우 수정 후 prerelease 태그 게시. CI가 있다고 통과했다고 주장하지 않습니다.

## 실제 사용자 환경에서 필요한 항목

1. Windows에서 CHECK_WINDOWS.bat 실행 후 Python/FFmpeg 상태 확인.
2. START_WINDOWS.bat으로 파일 선택→검사→보고서 열기 확인.
3. 보고서에서 정상 연출 선택·메모 작성→검토 파일 내보내기→보고서 재열기→불러오기 확인.
4. 다른 보고서의 검토 파일을 불러올 때 거부되는지 확인.

브라우저 자동 점검은 로컬 파일 URL 보안 정책에 차단되었습니다. 이는 GitHub 로그인 여부와 무관합니다. 실제 화면·다운로드·불러오기를 완료했다고 주장하지 않습니다. CLI 저장·불러오기와 모의 DOM 로직 검증은 통과했습니다.
